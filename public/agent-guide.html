Agent & data access

BACnet Studio is a static, client-side application. Browser-capable agents can operate its labeled controls; agents that need to inspect or generate project files should use the published JSON Schemas.

Project files

Planner and diagram files are separate JSON formats. Both current formats use version: 2. The app accepts supported version 1 files and migrates them during import. Validate generated files against the appropriate schema before selecting Load plan or Open JSON.

The Diagram Builder also exports a legacy version 1 file. That compatibility export omits physical-layer data and is not the preferred interchange format.

Browser automation

  1. Navigate directly to the tool’s hash route.
  2. Use accessible names and visible labels instead of layout-dependent coordinates.
  3. Wait for reactive previews and diagnostics after changing a field.
  4. Treat reset, clear, replace, remove, and import actions as potentially destructive.
  5. Expect downloads to be generated locally as browser blobs.
No remote API: BACnet Studio does not currently provide REST, GraphQL, OpenAPI, or MCP tools. Calculations and project state remain in the browser.
